# Evolve Revival

Community tools to keep Evolve playable. Unofficial. Not 2K. Not Turtle Rock.

The game files are not here. This org is the launcher, overlay, and docs so other people can keep building.

## Repos

- [evolve-launcher](https://github.com/DISRVPT-DEV/evolve-launcher) — Windows launcher. Download or repair Evolve, apply RiceFix, host or join over Radmin VPN, friends and party, in-game overlay.

## Play

1. Install [Radmin VPN](https://www.radmin-vpn.com/) from the official site.
2. Grab `evolve-launcher.exe` from [evolve-launcher/release](https://github.com/DISRVPT-DEV/evolve-launcher/tree/main/release/EvolveRevival-Launcher).
3. First run downloads the game. Host or join on the same Radmin network.

## Build

Clone [evolve-launcher](https://github.com/DISRVPT-DEV/evolve-launcher) and follow the README. PRs welcome. Two-person custom match is still the real proof.
