# Evolve Revival

Community tools to keep Evolve playable. Unofficial. Not 2K. Not Turtle Rock.

This started in the [Evolve Revival Discord](https://discord.gg/m2rqJNuKfJ). That is where the files, RiceFix, and the people still playing live. Come sit there if you want to play or help.

The game files are not here. This org is the launcher, overlay, and docs so other people can keep building.

## Repos

- [evolve-launcher](https://github.com/DISRVPT-DEV/evolve-launcher) — current Windows launcher. Download or repair Evolve, apply RiceFix, host or join over Radmin VPN, friends and party, in-game overlay.
- [evolve-revival/evolve-launcher](https://github.com/evolve-revival/evolve-launcher) — the original public launcher this work is built on. I took that June snapshot and kept going.

## Play

1. Join the [Discord](https://discord.gg/m2rqJNuKfJ).
2. Install [Radmin VPN](https://www.radmin-vpn.com/) from the official site.
3. Grab `evolve-launcher.exe` from [evolve-launcher/release](https://github.com/DISRVPT-DEV/evolve-launcher/tree/main/release/EvolveRevival-Launcher).
4. First run downloads the game. Host or join on the same Radmin network.

## Build

Clone [evolve-launcher](https://github.com/DISRVPT-DEV/evolve-launcher) and follow the README. PRs welcome. Two-person custom match is still the real proof.
